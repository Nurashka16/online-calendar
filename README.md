# Календарь событий — веб-приложение

Это простое и удобное веб-приложение для создания и просмотра календарей событий. Позволяет пользователям:
- Создавать уникальные календари,
- Добавлять события с датами и описанием,
- Просматривать события в формате календаря (месяц/неделя/день),
- Входить в существующие календари по ссылке или коду.
Проект идеально подходит как для личного использования, так и для небольших команд, которым нужен легковесный инструмент планирования без лишней сложности.
---

> Разработано мной: 
- **HTML5 / CSS3** – семантическая разметка и стилизация страниц.
- **JavaScript (ES6+)** – интерактивность: работа с датами, модальными окнами, обновление данных без перезагрузки.
---

## Установка и запуск
> Склонируйте репозиторий:
```bash
git clone https://github.com/vitek-5/calendar_project.git
cd calendar_project
```

> Запустите установочный скрипт:
```bash
python install.py
```

Следуйте инструкциям в терминале:
- Введите имя базы данных
- Укажите логин и пароль PostgreSQL

Скрипт сделает за вас:
- Создаст виртуальное окружение
- Установит зависимости
- Выполнит миграции
- Соберёт статику
- Предложит запустить сервер

> Откройте приложение в браузере:
```
http://127.0.0.1:8000
```
---

## Админ-панель
Вы можете создать суперпользователя для управления данными:

```bash
python manage.py createsuperuser
```

Затем откройте админку:
```
http://127.0.0.1:8000/admin/
```
